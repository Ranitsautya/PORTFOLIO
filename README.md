# Ranit Sautya — Portfolio

A responsive, dark-themed portfolio for **Ranit Sautya**, Full Stack AI/ML Engineer and Generative AI Developer. Built with plain HTML, CSS, and vanilla JavaScript.

## Features

- Responsive portfolio sections for About, Projects, Generative AI, Skills, Education, Resume, and Contact
- Draggable, hideable side navigation
- Animated canvas backgrounds, scroll reveals, and project-card interactions
- Project source links and a browser-playable Flappy Game
- Resume preview on larger screens, with full-screen view and download options on mobile
- Reduced-motion support

## Run locally

There is no build step or package installation. Open `index.html` in a browser, or serve the folder with a static file server for the best PDF preview experience. In VS Code, you can use the Live Server extension and choose **Open with Live Server** from `index.html`.

## Files

```text
Ranit_Portfolio/
├── assets/
│   └── Ranit_Sautya_Resume.pdf
├── index.html
├── script.js
├── style.css
└── README.md
```

The site uses Google Fonts as its only external visual resource. Project and social URLs are configured in `script.js`; section content and certificate links are in `index.html`.
